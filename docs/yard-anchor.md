# Yard 固定方块

`YardAnchorTile` 继承 `KeybindCircuitTile`，对应物品为 `YardAnchor`。
一个木材可合成一个。它是 1×1 实心方块，不可锤成斜坡。
使用与推进器相近的蓝灰金属像素纹理：未激活时中心暗淡，激活且未被致动时中心亮起青色。
两个状态各使用 16×16 图案，方块纹理带 2 像素透明帧间距，物品图标使用未激活图案。
每块方块独立显示边框，不与相邻块合并；贴图切换使用已同步的电路状态，不修改存储帧。
素材由内置 imagegen 生成，再以最近邻采样适配游戏像素尺寸，提示词见 [纹理生成记录](yard-anchor-textures.md)。

主世界中可放置和右键绑定快捷键；采集进 Yard 后才能响应按键或电线。
玩家深度绑定到该 Yard 后，可在任意距离按住快捷键激活；电线脉冲按基类规则切换开关。
快捷键不会主动发送电线脉冲。按键或电路任一输入有效时，设备保持激活。

任一未被致动的固定方块激活时，整个 Yard 切换为 Box2D 静态刚体，停在当前位置和角度，
仍可阻挡动态 Yard。所有固定方块解除激活、被拆除或被致动为虚体后，恢复动态刚体。
两个方向的切换都清零线速度和角速度，不保存或恢复之前的动量；恢复动态后的同次物理步进
正常接受重力、推进器和碰撞，因此该步结束时速度可能已不为零。

刚体因方块编辑重建时保留静态类型。切换只在单人或服务器执行，客户端继续接收权威姿态
及电路激活状态。激活状态沿用基类规则，不写入世界存档；重进后按当前输入重新激活。

## 人工验收

1. 在移动并旋转的 Yard 中按住固定方块快捷键，确认位置和角度固定；松开后从零动量恢复运动。
2. 使用电线脉冲开关；按键与电线同时激活后松键，电路未关闭时仍保持固定。
3. 放置两个固定方块，分别激活；只关闭一个时仍固定，最后一个关闭后恢复动态。
4. 固定时开动推进器、施加测试力或让另一个 Yard 撞击，确认固定 Yard 不移动；解除后不恢复旧速度。
5. 固定时增删其他实体方块，确认碰撞体重建后仍固定；拆除或致动最后一个有效固定方块后恢复动态。
6. 主世界中按键或电线不产生固定效果；采集和放回后快捷键绑定仍随方块转移。
7. 两名玩家联机验证按键与电线组合、解除深度绑定、死亡、断线和中途加入，确认客户端姿态一致。
8. 检查主世界方块与物品图标显示未激活图案；Yard 内按键、电线切换、拆除和致动时贴图随状态变化。
   相邻摆放、旋转、涂漆和客户端中途加入后仍应使用正确帧，不出现裁切或重复边框。

开发验证使用仓库的 compile-only 构建命令；上述场景留待游戏内人工验证。
