# 床与椅子的原版实现检查

检查依据是当前安装的 `tModLoader.dll` 中 `PlayerSittingHelper`、`PlayerSleepingHelper`
以及 `Player.CanSnapToPosition` 的 IL。下面的原版分析来自之前的源码探索；当时尚未接入 Yard 家具姿态。
当前已完成坐下与床头睡眠适配，实现与人工验收见文末；移动床的出生点仍未接入。

## 椅子

`PlayerSittingHelper.GetSittingTargetInfo` 从 `Framing.GetTileSafely(x, y)` 读取 Tile，检查
`CanBeSatOnForPlayers`，根据类型和帧确定家具局部段、朝向和锚点。它通过
`TileRestingInfo` 调用 `TileLoader.ModifySittingTargetInfo`，允许 Mod 修改锚点、视觉偏移和朝向。
输出的 `playerSittingPosition` 是直接从 Tile 格换算出的世界像素坐标。

`SitDown` 计算 `playerSittingPosition - player.Bottom`，交给 `CanSnapToPosition` 判断。
它还通过 `Main.sittingManager` 检查同一格的座位占用，当前要求叠坐索引小于 2。
通过后停止已有姿态、移除钩爪并卸下坐骑，直接设置 `player.Bottom` 和朝向，
保存 `isSitting`、`details`、`offsetForSeat`、`sittingIndex`，清零速度并设置 `gravDir = 1`。
本地玩家发送原版 `PlayerControls` 同步。

`UpdateSitting` 每次更新用 `(player.Bottom + (0, -2)).ToTileCoordinates()` 重新找家具，
而不是读取独立保存的 Yard ID / 局部锚点。家具失效、输入移动或跳跃、进入滑轮/坐骑、
朝向不符或占用超限都会触发 `SitUp`。继续坐下时重新登记占用并更新座位视觉信息。

`GetSittingOffsetInfo` 输出绘制偏移和角色坐姿相关高度偏移，包含叠坐索引、朝向、重力及
`offsetForSeat`；坐姿不是简单修改玩家碰撞框尺寸。

## 床

`PlayerSleepingHelper.GetSleepingTargetInfo` 检查 `CanBeSleptIn`，从 Tile 帧还原床的段、
朝向和样式，通过 `TileLoader.ModifySleepingTargetInfo` 允许 Mod 调整 `TileRestingInfo`。
同样将锚点格直接换算成世界像素，输出目标 `Bottom` 和 `visualOffsetOfBedBase`。

`StartSleeping` 使用相同的 `CanSnapToPosition` 和占用检查。开始睡眠时停止其他姿态，
移除钩爪和钓鱼浮标，卸下坐骑，设置 `Bottom`、朝向、占用索引，清零速度并恢复正常重力。
`SetIsSleepingAndAdjustPlayerRotation` 设置睡眠标志及
`player.fullRotation = -player.direction * π/2`，使玩家视觉上横躺。
`StopSleeping` 恢复 `fullRotation = 0` 并清理睡眠偏移和计时。

`UpdateState` 递增 `timeSleeping`，同样根据玩家 `Bottom` 附近的世界格重新检查床。
移动、跳跃、家具失效、占用超限等条件会停止睡眠；活动和环境条件还会重置入睡时间。
`GetSleepingOffsetInfo` 负责床样式及多人占用对应的视觉偏移。
睡眠 helper 与床右键设置出生点是不同路径；本次未修改出生点处理。

## 吸附校验与 Yard 的差异

`CanSnapToPosition` 接收位移，不只判断交互距离。它调用主世界的 `Collision.SolidCollision`、
`Collision.CanHit`，并在必要时尝试沿玩家宽度移动后检查路径，期间使用 `Collision.TileCollision`。
只放行 Tile 存储边界无法让这套世界坐标吸附检查正确处理 Yard。

两类 helper 都将家具格视为世界格，直接改变玩家的持久 `Bottom`，并在后续更新里从玩家世界位置
反推家具格。如果把存储格直接传进去，目标会落在存储区的像素位置；仅在进入时把目标换回世界，
后续重新找家具仍会失败。因此需要独立的 Yard ID / 局部锚点、每帧的世界位置还原，
以及相应占用/绘制处理。当前 Yard 交互不沿用原版 `CanSnapToPosition` 的路径检查，
也不额外实现 Yard 几何吸附检查；进入检查保留家具、距离和占用条件。

## 当前适配

`Common/Players/YardRestingPlayer.cs` 保存家具姿态，不借用普通接触绑定。
进入时用原版 `GetSittingTargetInfo` / `GetSleepingTargetInfo` 读取存储 Tile，
把其目标 Bottom 转为局部像素，记录规范家具格、类型/帧和朝向，并按原版初始化姿态字段。
会停止已有姿态、移除钩爪、卸下坐骑；睡眠另外移除浮标，恢复正常重力。
主世界位置只接受变换后的 Bottom，存储地址不会进入玩家位置、相机或原版玩家控制包。

`Common/TileYards/YardSystem.Resting.cs` 为三个原版每帧家具查询增加 IL 接入点，
将由世界 Bottom 得到的 Tile 格替换为当前绑定的存储锚点；主世界家具保持原路径。
原版 helper 继续处理输入起身、姿态偏移、占用索引、睡眠中断和入睡计时。
右键距离和鼠标提示使用 Yard 的逆变换坐标，床尾的出生点提示被移除。

进入和持续随动均不检查玩家碰撞框、目标穿透或吸附路径，不与本 Yard 或其他 Yard 做玩家碰撞检测，
也不额外预扫主世界障碍来裁剪锚点随动或触发起身。家具换帧/移除/致动以及 Yard 放回/失效仍会解除姿态。
普通移动绑定在姿态期间暂停，每更新将局部 Bottom 还原到当前玩家姿态，防止双重载体位移。
起身后一次性继承锚点速度，随后按既有实体接触规则恢复普通绑定。
每帧原版更新前先移除坐卧玩家的载体速度；起身保留当帧碰撞查询和退出前的载体姿态，
恢复普通绑定时按实体接触规则处理，避免重复继承速度。
玩家绘制先保留原版坐姿或睡眠横躺，再围绕显示姿态的家具锚点旋转完整绘制数据，
包含床样式和叠坐偏移；身体随结构旋转，本地深度绑定视角抵消结构旋转和锚点位移。

多人进入经服务器的距离、家具和占用校验；规范锚点每种姿态最多两人。
`PlayerRest` 同步 Yard ID、点击局部格、姿态和服务器朝向；退出请求只能影响发送者的当前绑定。
入服/全量快照后补发姿态，尚未加载的 Yard 暂存权威状态；普通乘客位置包不能覆盖家具锚点。
姿态不进入存档。自定义 ModTile、移动床出生点和驾驶尚未适配。
玩家保留原版碰撞框及弹幕、NPC 等命中/伤害流程，原版玩家更新照常执行；
锚点位置由家具控制，碰撞框不随 Yard 旋转，不新增旋转身体轮廓或禁用原版伤害。

坐下与睡眠已接入 [深度绑定参考系](yard-prototype.md#深度绑定参考系)：
交互进入/结束时显式开启/关闭深度绑定，状态本身只要求一个有效的绑定 Yard。
家具检查、移动限制和起身规则仍由交互负责；深度绑定不增加逐帧静止、接触或范围检查，
并沿用上述不检测 Yard 玩家碰撞、自然保留原版碰撞框的规则。
本地视角跟随玩家锚点并抵消 Yard 的旋转，使玩家屏幕位置固定、Yard 画面方向稳定，外部世界相对旋转。
完整世界绘制到扩展画布后合成，UI 保持正常，鼠标使用视角逆变换；实现及额外验收见上述参考系章节。

## 人工验收

编译使用仓库的 compile-only 命令；以下场景需在游戏中人工检查，本次未启动游戏：

1. 搬运含完整椅子、沙发/长凳、马桶及左右朝向床的 Yard。右键椅子坐下、床头睡眠，
   确认不同样式的身体/家具对齐；床尾不设置或移除原出生点，主世界床仍保留两种交互。
2. 使用施力测试器或结构碰撞使 Yard 平移、倾斜，确认玩家持续随动、坐姿/横躺随结构旋转，
   无重力下坠、双重位移或存储区瞬移。本地画面中玩家锚点固定在屏幕中心、船体方向稳定，
   主世界反向旋转、UI 不转；停止施力后仍应正常随动。
3. 用移动键、跳跃、坐骑或再次右键同一规范座位退出；睡眠时使用会中断睡眠的物品。
   确认原版起身和睡眠中断正常，起身后不重复叠加惯性，视角立即恢复世界方向。
4. 在交互距离内用 Yard 实体遮挡吸附路径或与玩家框重叠，确认不会因几何检查拒绝坐卧；
   让载体旋转或靠近另一个 Yard，确认不会因玩家与 Yard 重叠而自动起身。
   用原版弹幕或敌怪攻击玩家，确认仍正常命中、受伤和死亡，未出现免伤或消失的玩家碰撞框；
   靠近主世界障碍时检查原版碰撞/伤害流程仍运行，锚点随动不增加受阻退出。
   移除/致动/切换家具帧、放回 Yard、死亡及退出世界后确认无残留锚点。
5. 两名玩家坐同一规范座位或睡同一床，检查叠坐/睡眠偏移；第三名玩家不能进入已满锚点。
   在两个显示重叠、存储边缘紧贴的 Yard 上交互，确认占用和家具定位不会串扰。
6. 联机由 A 坐下/睡眠，B 观察姿态与运动；特别检查沙发上不同初始朝向的玩家。
   A 以绑定 Yard 为参考系，未深度绑定的 B 保持世界方向；两人绑定不同 Yard 时视角各自独立。
   B 中途加入、请求全量重同步或短暂延迟后，确认家具姿态恢复且站立乘客同步仍正常。
   A 起身、死亡、断开或放回 Yard 后，B 应同步退出；睡眠保持原版入睡和环境中断规则。
7. 保存退出后重进，确认 Yard 和家具仍在、姿态不自动恢复；主世界的椅子与床不受影响。
8. 单人坐椅子或睡床时让船高速旋转，主动起身后让船以可行走倾角停稳。
   从主世界地面重新走上船，在两个方向分别上坡、下坡、站立、跳跃，并再次坐下或睡眠；
   确认无持续下落姿态、上坡被下滑速度抵消或贴地家具无法吸附。保持倾角保存退出并重进后重复。
   在吸附路径中放 Yard 实体、终点与 Yard 实体重叠，确认不会因碰撞预检查拒绝进入；
   自由旋转时也检查坐卧保持。退出后确认普通行走与 Yard 碰撞恢复。
